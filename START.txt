Локальная scoped read-only прила доступа AI к твоим TG-чатам.
Полный план: PRD.md (задачи T0..T8).

── ЧТО СДЕЛАТЬ ПЕРЕД КОДОМ ──────────────────────────────────
1) Получи Telegram API-креды:
   → my.telegram.org → API development tools → Create application
   → скопируй  api_id (число)  и  api_hash (строка)

2) Создай .env в этой папке (projects/netgram/.env):
   TELEGRAM_API_ID=12345678
   TELEGRAM_API_HASH=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   TELEGRAM_PHONE=+995XXXXXXXXX
   (.env уже будет в .gitignore — в репо НЕ попадёт)

── ЛОГИКА СТАРТА (из PRD) ───────────────────────────────────
  нет env-переменных      → пишем «нет нужных переменных»
  есть креды, нет сессии  → ждём TG-код (логин)
  всё есть + сессия       → запуск в ЛК

── ДАЛЬШЕ ───────────────────────────────────────────────────

  T0 = спайк GramJS: логин + вывод списка чатов в консоль.
  Потом T1 (скелет Next.js) → ... → T8 (e2e).
