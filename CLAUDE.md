# CLAUDE.md — netgram

## GramJS auth — не спамить SignIn

Никогда не давай GramJS `client.start()` retry-цикл на `phoneCode`/`password`,
который молча повторяет один и тот же (уже отклонённый) код. При
`PHONE_CODE_INVALID` GramJS по умолчанию просто снова зовёт колбэк — если
в нём захардкожено одно и то же значение, получится цикл невалидных попыток
за секунды, и Telegram отвечает `FloodWaitError` (блок на десятки минут,
однажды было ~56 мин).

Правило: колбэк `phoneCode`/`password` должен отдать код **максимум один
раз** и после первого отказа сразу `process.exit(1)` / throw с понятной
ошибкой — не повторять тот же ввод молча. Если код не подошёл — нужен новый
код от пользователя, а не повторная попытка со старым.
